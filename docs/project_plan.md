## Current Phase

## Phase 1 — CSI Acquisition

- ESP32 CSI generation
- Raspberry Pi / Nexmon setup
- Establishing the CSI data path
- Capturing CSI
- Determining the actual data/packet format
- Evaluating possible acquisition methods
- Selecting the final acquisition method
- Validating that the acquired data is actually CSI

### Phase 1 Deliverable

A reproducible and verified CSI acquisition pipeline.

## Phase 2 — CSI Representation

- Parsing
- Data representation/storage
- Visualization
- Validation of the resulting data

### Phase 2 Deliverable

Clean, usable CSI dataset and visualization.

## Phase 3 — Signal Processing

- Amplitude/phase processing
- Filtering
- Noise handling
- Normalization
- Relevant signal-processing techniques

### Phase 3 Deliverable

Processed CSI suitable for downstream analysis.
